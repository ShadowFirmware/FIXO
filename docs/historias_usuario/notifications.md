# Módulo 6. Notificaciones

## 6.1 Recibir notificaciones sobre incidencias y reportes de conducta

**Prioridad:** Alta

Como usuario del sistema, quiero recibir notificaciones relacionadas con las incidencias y los reportes de conducta que me correspondan, para mantenerme informado sobre eventos o cambios importantes dentro del sistema.

### Criterios de aceptación

- El residente que registró la incidencia (o el residente activo del departamento) deberá recibir una notificación cuando su incidencia sea asignada a un técnico.
- El residente deberá recibir una notificación cuando exista información relevante sobre la atención de su incidencia, incluyendo la información del técnico y la hora estimada de llegada.
- El residente que registró la incidencia (o el residente activo del departamento) deberá recibir una notificación cuando su incidencia sea marcada como Resuelta.
- El técnico deberá recibir una notificación cuando se le asigne una nueva incidencia.
- La notificación de asignación deberá permitir identificar el reporte correspondiente.
- El administrador deberá recibir una notificación cuando se registre una nueva incidencia pendiente de asignación.
- El administrador deberá recibir una notificación cuando se genere un nuevo reporte de conducta contra un residente o un técnico.
- Cuando un reporte de conducta sea validado, el usuario reportado deberá recibir una notificación de advertencia.
- Cuando la cuenta sea suspendida, la notificación deberá indicar la duración de la suspensión.
- Cuando finalice una suspensión temporal, el usuario deberá recibir una notificación indicando que su cuenta ha sido reactivada.
- Cuando el quinto reporte sea validado, el usuario deberá ser notificado de que su cuenta fue deshabilitada indefinidamente.
- Si el administrador posteriormente reactiva una cuenta deshabilitada indefinidamente, el usuario deberá recibir una notificación de reactivación.
- El residente deberá recibir una notificación cuando su incidencia sea rechazada, incluyendo el comentario.
